Take 3 distinct integers a,b,c as input and return the second smallest among the input.


import java.util.*;

public class Main {
    public static void main(String[] args) {
      Scanner sc = new Scanner(System.in);

        // Read three integers
        int a = sc.nextInt();
        int b = sc.nextInt();
        int c = sc.nextInt();

        int secondSmallest;

        // Check which is the second smallest
        if ((a > b && a < c) || (a > c && a < b)) {
            secondSmallest = a;
        } else if ((b > a && b < c) || (b > c && b < a)) {
            secondSmallest = b;
        } else {
            secondSmallest = c;
        }

        System.out.println(secondSmallest);
  }
}


Take 3 integers A,B,C which denote the angles of a triangle, and return 'VALID' if the angles can form a valid triangle or 'NOT VALID' if the angles cannot form a valid triangle. Print the type of triangle in case it is valid


import java.util.*;

public class Main {
    public static void main(String[] args) {
      Scanner sc = new Scanner(System.in);

        // Read three angles
        int A = sc.nextInt();
        int B = sc.nextInt();
        int C = sc.nextInt();

        // Check if the angles form a valid triangle
        if (A > 0 && B > 0 && C > 0 && (A + B + C == 180)) {
            System.out.println("VALID");

            // Determine the type of triangle
            if (A == B && B == C) {
                System.out.println("EQUILATERAL");
            } else if (A == B || B == C || A == C) {
                System.out.println("ISOSCELES");
            } else {
                System.out.println("SCALENE");
            }

        } else {
            System.out.println("NOT VALID");
            System.out.println();
        }
  }
}

Take a 3 digit integer, print "YES" if the reversed integer is equal to the input. Print "NO" otherwise.

import java.util.*;

public class Main {
    public static void main(String[] args) {
      Scanner sc = new Scanner(System.in);

        // Read the three-digit number
        int num = sc.nextInt();

        // Extract digits
        int hundreds = num / 100;
        int tens = (num / 10) % 10;
        int units = num % 10;

        // Reverse the number
        int reversed = units * 100 + tens * 10 + hundreds;

        // Check if reversed number equals original
        if (num == reversed) {
            System.out.println("YES");
        } else {
            System.out.println("NO");
        }
  }
}

Take marks in five subjects,find the average and return the corresponding grade .
Rules for grade:
Average > = 90 - A
Average > = 80 and less than 90 - B
Average > = 70 and less than 80 - C
Average > = 50 and less than 70 - D
Other cases: F

import java.util.*;

public class Main {
    public static void main(String[] args) {
      Scanner sc=new Scanner(System.in);
      int a=sc.nextInt();
      int b=sc.nextInt();
      int c=sc.nextInt();
      int d=sc.nextInt();
      int e=sc.nextInt();
      int avg=(a+b+c+d+e)/5;
      if (avg >= 90) {
            System.out.println("A");
        } else if (avg >= 80) {
            System.out.println("B");
        } else if (avg >= 70) {
            System.out.println("C");
        } else if (avg >= 50) {
            System.out.println("D");
        } else {
            System.out.println("F");
        }
  }
}
