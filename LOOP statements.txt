Take a number and return all the even digits of the number.

import java.util.*;

public class Main {
    public static void main(String[] args) {
      Scanner sc=new Scanner(System.in);
      int a=sc.nextInt();
      boolean foundEven=false;
      String numStr=String.valueOf(a);
      for(int i=0;i<numStr.length();i++){
        int digit=numStr.charAt(i)-'0';
        if(digit%2==0){
          System.out.println(digit);
          foundEven=true;
        }
      }
      if(!foundEven){
        System.out.println(-1);
      }
  }
}

Take an integer an return 'YES' if the input is a palindrome, or 'NO' if it is not.

import java.util.*;

public class Main {
    public static void main(String[] args) {
      Scanner sc=new Scanner(System.in);
      int n=sc.nextInt();
      int rev=0,n1=n;
      while(n>0){
        rev=(rev*10)+n%10;
        n=n/10;
      }
      if(n1==rev){
        System.out.println("YES");
      }
      else{
        System.out.println("NO");
      }
  }
}

For number from 1 to 100 if number is divisible by 3 print 'Hello' if divisible by 5 print 'World', if divisible by 15 print 'HelloWorld' else print the number itself

public class Main {
    public static void main(String[] args) {
      for(int i=1;i<=100;i++){
      if(i%3==0 && i%15!=0){
        System.out.println("Hello");
      }
      else if(i%5==0 && i%15!=0){
        System.out.println("World");
      }
